# Textkit — open Ancient Greek and Latin textbook library

`https://www.textkit.com/` — an open-textbook project running since
2001: a library of 180+ public-domain Ancient Greek and Latin
textbooks, readers, and answer keys as free PDFs (e.g. White's *First
Greek Book*, D'Ooge's *Latin for Beginners*, and a PDF of Smyth's *Greek
Grammar* — see
[`references/sources/grammar-references.md`](grammar-references.md) for
Smyth's separately-hosted, structured Perseus edition), plus a learner
community forum. All library content is licensed **CC BY-SA 3.0**.

**Status: not integrated.** A real bulk-downloadable, openly-licensed
PDF library — unlike a paywalled or view-only source, the material is
genuinely reusable — but each item is a scanned/typeset PDF, not
structured text, so extraction would need real OCR/PDF-parsing work per
title, not just a download. Candidate as a source of additional
public-domain reading texts/grammars if this KB ever needs one beyond
what's already covered by LSJ, Wiktextract, and the grammar references
already documented; nothing pulls from it yet.
