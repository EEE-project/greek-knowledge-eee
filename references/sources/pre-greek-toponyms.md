# Pre-Greek toponyms dataset (Hieber)

A companion dataset to
[`references/sources/pre-greek-substrate-overview.md`](pre-greek-substrate-overview.md),
hosted on Notion at
`resources.linguisticdiscovery.com/pre-greek-toponyms`. Catalogs Ancient
Greek place names judged Pre-Greek in origin, ranked by certainty; a
public map layer plots only the highest-certainty subset — those with
the well-attested Pre-Greek suffixes `-μν-`, `-ν-`, `-νθ-`, and
`-σσ-`/`-ττ-`. The full dataset, including lower-certainty and
map-excluded toponyms, is viewable on the same page.

**Status: not integrated.** View-only Notion page — a plain HTTP fetch
returns an empty JS-rendered shell, not the actual content, and no
CSV/JSON export or API was found. No license is stated. Manual-citation
candidate only: a human (or an LLM with a rendered view of the page)
would need to transcribe specific toponym entries, the same access
profile as Beekes' EDG (see
[`references/sources/beekes.md`](beekes.md)).
