# CLARIN Virtual Language Observatory (VLO)

`https://vlo.clarin.eu/` — a faceted search interface aggregating
metadata for roughly 975,000 language-resource records contributed by
many institutions and archives across CLARIN's pan-European research
infrastructure. Not a single resource or dataset in its own right, and
not Greek- or Pre-Greek-specific — a discovery tool over resources
hosted elsewhere.

**Status: not integrated, and not a citable source in the sense the rest
of this list is** — there is no single dataset here to cite from, only a
catalog for finding one. No REST/OAI-PMH/SRU API was confirmed from the
pages checked (web UI faceted search only); CLARIN's broader
infrastructure may expose harvesting APIs elsewhere, but that wasn't
verified. Value here is as a discovery starting point if a specific new
Ancient or Modern Greek resource is ever needed — not a build-time
dependency candidate. See
[`references/sources/european-language-grid.md`](european-language-grid.md)
for the equivalent EU catalog aimed more at language-technology tools
than raw datasets.
