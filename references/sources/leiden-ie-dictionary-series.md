# Leiden Indo-European Etymological Dictionary Series (Brill)

Brill's ongoing series (project set up 1991, ~12 volumes published),
each volume a complete etymological dictionary of one Indo-European
branch, cross-referenced against shared Proto-Indo-European
reconstructions. Notable volumes: de Vaan, *Etymological Dictionary of
Latin and the Other Italic Languages* (vol. 7, 2008); **Beekes,
*Etymological Dictionary of Greek* (vol. 10, 2010) — the volume this KB
already uses, see**
[[`references/sources/beekes.md`](beekes.md)](beekes.md); Kroonen, *Etymological
Dictionary of Proto-Germanic* (vol. 11, 2013); plus Slavic, Baltic,
Celtic, Armenian, and Tocharian volumes by other authors.

**Status: not integrated beyond the Greek volume already covered by
`beekes.md`.** Subscription/purchase-only publisher series — a direct
fetch of Brill's series page returned HTTP 403 (scripted access
blocked); no open digital edition or bulk/API access exists for any
volume, the same access profile `beekes.md` already documents for the
Greek volume specifically. The non-Greek volumes (Latin, Germanic, etc.)
would only become relevant if this KB ever needs comparative
cross-branch IE cognate citations beyond single-word Greek etymology —
no current use case. For an openly-licensed alternative covering
cross-branch cognate data (not full dictionary entries), see
[[`references/sources/iecor.md`](iecor.md)](iecor.md).
