# Grammatical Rules

One file per documented grammatical rule -- a synchronic paradigm/syntax
rule scoped to one period, or a period-to-period change. Filename = a
short kebab-case slug (e.g. `aorist-3pl-osan.md`). Hand-authored, not
generated -- copy [[`templates/grammar-rule.md`](../templates/grammar-rule.md)](../templates/grammar-rule.md)
to start a new one, then run `uv run greek-knowledge check` to validate it.
