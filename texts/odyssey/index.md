# Odyssey — Literary Text and Literary Translation entries

Concept files for the Odyssey (I.1-21, IX.19-180): `text.md` (a Literary
Text -- the Ancient Greek original, hand-authored from the `grc:` echo lines
below, not produced by the script mentioned further down),
`translations_en.md` (Pope, Murray, Chapman, interlinear_en), `translations_ru.md`
(Жуковский, Вересаев, interlinear_ru), `translations_el.md` (Πολυλάς, Σπανούδης, interlinear_el).
Each interlinear translator's stanza text echoes its Greek source line as
an `<!-- grc: ... -->` comment (stripped via `GreekUtils.strip_comment_lines()`)
ahead of the plain word-by-word gloss. Populated by
`scripts/populate_odyssey_texts.py`, a one-off, re-runnable script —
not the general build pipeline ([`okfbuild/pipeline.py`](../../okfbuild/pipeline.py)) — since there
is no live source to query for a human translation; see that script's
own docstring for why this content lives here rather than being
live-queried.

## Reading it

```bash
uv run greek-knowledge query --type texts --work odyssey --language ru --full  # --language grc/en/el for the others, comma-separated for several; drop it for all four
cat texts/odyssey/text.md                       # the Ancient Greek original
cat texts/odyssey/translations_en.md            # Pope, Murray, Chapman, interlinear_en
cat texts/odyssey/translations_ru.md            # interlinear_ru, Жуковский, Вересаев
cat texts/odyssey/translations_el.md            # Πολυλάς, Σπανούδης, interlinear_el
awk '/^## Murray/{f=1;next} /^## /{f=0} f' texts/odyssey/translations_en.md   # one translator's section
```

## The Cypriot-dialect translation (Σπανούδης)

`translations_el.md` holds fragments of Άκης (Μιχαλάκης) Σπανούδης's *Ομήρου Οδύσσεια στην κυπριακή διάλεκτο* (Β' έκδοση, Λάρνακα: Χαβιαράς & Φιλίππου ΔΕΠΕ, 2020, ISBN 978-9963-2489-1-9; γλωσσική επιμέλεια Κώστας Κατσώνης): a free rendering in rhymed couplets of fifteen-syllable verse, which the preface says was made from a Modern Greek version rather than from the ancient text. It is in copyright (the imprint forbids any reproduction without the creator's written permission), so the section holds fragments only -- 178 of the work's 11,076 verses (Ραψωδία Α' στ. 1-30 and Ι' στ. 19-166) -- on the maintainer's statement that the translator permitted the use of fragments in the maintainer's demo. The rest of the translation is not reproduced here.

Because the rendering is free, its verses do not match the Greek line for line. They were assigned to the lessons' stanzas by sense, verse by verse: a stanza's block holds the consecutive verses that render its Greek lines, so it can begin or end a verse before or after them, and a rhymed couplet is split where its two verses render different stanzas (11 couplets are), and a verse that renders Greek lines of two stanzas is repeated in both blocks (`Ι' 35`, `70`, `71`, `117` and `136`: the 178 verses make 183 verse lines). The rendering also condenses and reorders: `IX.29–33` has two verses only (`Ι' 29–30`, which render the Circe lines; the Calypso lines have no counterpart), and `Ι' 71` renders `IX.75` but follows the verse that renders `IX.76`, so `Ι' 70–71` stand in both `IX.72–75` and `IX.76–78`. The comment `<!-- Ραψωδία … στ. … -->` under each stanza heading names the verses of the edition that the block holds. The edition's own verse numbers are not kept. Its asterisks are (`word*` in the verse), and so are its margin notes, which give each starred Cypriot word in standard Greek: one `<!-- gloss: word — meaning -->` comment line right after the verse (several notes of one verse are joined with ` · `). A lesson reads these lines before it strips the comments, as it does the `grc:` echoes of the interlinear sections, and shows each note beside its verse. The text follows the printed pages letter for letter, including what looks like a slip (Ι' στ. 71 «εννοιες», 90 «με στους», 103 «Με σπέρνουν», 153 «Κίκονες» where the Greek has the Cyclopes); the transcription that the maintainer first supplied differed from the book in many Cypriot spellings and a few words, so the book was followed. The one liberty is a space after the comma in a margin note that prints none (Α' στ. 1).

```bash
uv run greek-knowledge query --type texts --work odyssey --language el --full   # Πολυλάς, Σπανούδης and interlinear_el together
awk '/^## Σπανούδης/{f=1;next} /^## /{f=0} f' texts/odyssey/translations_el.md   # just the Cypriot section
```
